## Поток данных

1. **app** → инициализирует провайдеры
2. **pages** → использует виджеты
3. **widgets** → композирует фичи
4. **features** → использует сущности и shared
5. **entities** → работает с API через shared
6. **shared** → предоставляет базовые ресурсы

## Импорты (только вниз по слоям)

- ✅ `widgets` → `features`, `entities`, `shared`
- ✅ `features` → `entities`, `shared`
- ✅ `entities` → `shared`
- ✅ `shared` → только внешние библиотеки

## Примеры использования

### В виджете:
```tsx
import { ScheduleFilters, ScheduleList } from '@/features/schedule';
import { useCurrentDaySchedule } from '@/entities/schedule';
import { LoadingSpinner } from '@/shared/ui';
```

### В фиче:
```tsx
import { useCurrentDaySchedule } from '@/entities/schedule';
import { Button, Input } from '@/shared/ui';
```

### В сущности:
```tsx
import { scheduleApi } from '@/shared/api';
import { groupScheduleByCourse } from '@/shared/lib';
```
