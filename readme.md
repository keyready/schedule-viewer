# Schedule Viewer
WEB-приложение для просмотра расписания учебных занятий на факультете, представленных в .xlsx-таблицах

все что нужно `docker compose up -d --build`

Сервисы:
- Клиент: `http://localhost:${CLIENT_PORT-2000}` (по умолчанию `2000`)
- Сервер API: `http://localhost:${SERVER_PORT-6000}` (по умолчанию `6000`)
- MongoDB: порт `${MONGODB_PORT-27017}` (по умолчанию `27017`)

Примечания:
- При первом запуске импорт бэкапа MongoDB выполняется автоматически из `server/backup/dump` (если найден).
- Папка с Excel-файлами для парсера пробрасывается в контейнер: `server/files -> /app/files`.
- `NEXT_PUBLIC_API_URL` используется клиентом в браузере для обращения к API, поэтому по умолчанию указывает на хост-машину (`localhost:6000`).
